void Sliding\+Tiles\+Functions::\+shuffle (\begin{DoxyParamCaption}{}{}\end{DoxyParamCaption})}

Shuffles \doxylink{namespace_sliding_tiles_data_aa8b2e966ce262f9a08dc3b159491fb24}{Sliding\+Tiles\+Data::\+board} by repeatedly calling \doxylink{namespace_sliding_tiles_functions_a98a0dab6a2ff2ccfac628207b0dfbcf2}{slide(\+Sliding\+Tiles\+Enums::\+\+Direction)} with a random direction. The shuffle will not immediately backtrack, meaning it can\textquotesingle{}t slide one direction and then slide back the opposite direction immediately afterwards. \begin{DoxyPrecond}{Precondition}
\doxylink{namespace_sliding_tiles_data_aa8b2e966ce262f9a08dc3b159491fb24}{Sliding\+Tiles\+Data::\+board} is not empty and all rows contain at least one element. (i.\+e., the \doxylink{class_board_ae79027074c6db2fa29b0f62570aee7b8}{Board::\+has\+Empty\+Row()} call returns false.) 
\end{DoxyPrecond}
\begin{DoxyAuthor}{Author}
Fabio Bustamante Romillo 
\end{DoxyAuthor}
\begin{DoxyDate}{Date}
8.\+04.\+2026
\end{DoxyDate}
\begin{DoxyNote}{Note}
If the pre-\/condition is not met, the function returns early without modifying the data. 

The function Sliding\+Tiles\+Functions::\+\+Start\+Game(\+Sliding\+Tiles\+Enums::\+\+Difficulty) should be used before calling this function. 
\end{DoxyNote}
\begin{DoxyWarning}{Warning}
If either one of the dimensions of the \doxylink{namespace_sliding_tiles_data_aa8b2e966ce262f9a08dc3b159491fb24}{Sliding\+Tiles\+Data::\+board} is somehow equal to 1, this function will enter an infinite loop due to its incapability to backtrack. This should be impossible at the moment, but it is worth noting if this code is to be expanded on.
\end{DoxyWarning}
